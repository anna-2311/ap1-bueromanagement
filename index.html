Glossar: Wichtige EDV-Funktionen

SVERWEIS Sucht in der ersten Spalte einer Matrix nach einem Wert und gibt den Wert in der gleichen Zeile aus einer angegebenen Spalte zurück.
WENN Prüft eine Bedingung und gibt einen Wert zurück, wenn die Bedingung wahr ist, und einen anderen, wenn sie falsch ist.
ZÄHLENWENN Zählt Zellen in einem Bereich, der ein bestimmtes Kriterium erfüllt.
SUMMEWENN Addiert die Zellen in einem Bereich, der ein bestimmtes Kriterium erfüllt.
RUNDEN Rundet eine Zahl auf eine angegebene Anzahl von Stellen.
MITTELWERT Berechnet den Durchschnitt der Argumente.
WENNFEHLER Gibt einen festgelegten Wert zurück, wenn eine Formel einen Fehler auswertet; andernfalls das Formelergebnis.
